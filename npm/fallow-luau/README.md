# fallow-luau (npm)

Prebuilt CLI wrapper. Prefer:

```bash
npx fallow-luau --version
npm install -g fallow-luau
```

The package pulls the matching `@fallow-luau/<platform>` optional dependency, or downloads the GitHub Release asset on postinstall.

See the [repository README](https://github.com/3xjn/fallow-luau#installation) for cargo, Docker, and one-liner installers.
